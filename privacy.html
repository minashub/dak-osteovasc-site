Privacy policy: Dak OsteoVasc Cloud

Last updated: 2026-11-15

What the app accesses

The app uses Google Drive with the drive.file scope only. It creates one export folder and uploads the video files it rendered. It can access only files it created, never other Drive content.

What is stored

The OAuth refresh token is stored encrypted in Google Cloud Secret Manager in the owner's own project. Rendered videos and their manifests are stored in the owner's own Cloud Storage bucket and Google Drive.

Sharing

No data is sold, shared with third parties, or used for advertising. Google user data is not used to train any AI model.

Users

The app is used only by its owner. Access can be revoked at any time at myaccount.google.com/permissions.

Contact

Open an issue at github.com/MinaJe-hub/dak-osteovasc-site.
