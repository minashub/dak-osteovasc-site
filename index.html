Dak OsteoVasc Cloud

Dak OsteoVasc Cloud is a private research tool run by one researcher. It renders short educational videos about bone and blood-vessel biology and saves the approved video files to the researcher's own Google Drive.

It is not a public service and has no other users.

Google Drive access

The tool asks only for the drive.file permission. With it, the tool can see and change only the files and folders it created itself. It cannot read any other file in the Drive.
